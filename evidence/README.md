# evidence/

Put the **original** CyberDefenders lab files here to run the tools on real data
(for example `hp_challenge.pcap`, `shadow.log`, `sudoers.log`, `ps.log`).

Everything in this folder except this README is **git-ignored**, so lab artefacts,
password hashes and malware samples are never uploaded to GitHub.

Download the lab files from: https://cyberdefenders.org/blueteam-ctf-challenges/escaperoom/
Open them only inside an isolated virtual machine with networking disabled.
